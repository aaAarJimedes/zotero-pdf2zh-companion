# PDF2zh 本地伴侣

当前版本 **2.1.0**。在 Zotero 工具栏提供一个 Server 按钮，启动或复用本机服务，再用 Zotero 内置查看器打开服务页面。翻译与附件导入仍由 PDF2zh 主插件处理。

## 默认译文与排版增强

默认开启，右键现有 Server 按钮可取消勾选“译文与排版增强”。也可使用偏好 `extensions.zotero.pdf2zh.companion.qualityEnabled`。开关只影响后续任务，关闭后恢复原生引擎命令和保存的原生排版选项，不停止在途任务。

子插件在配置的 Server 中安装一个受保护执行入口及自己的运行文件，复用所选 Python、模型、API 配置、工作数、限速和术语设置，不另建翻译服务。首次安装入口后，已运行的 Server 需要在任务结束后重启一次；安装器会提示，不自行结束任务。Server 升级覆盖入口后再次打开按钮会检查并重装，未知执行器源码拒绝修改。卸载子插件前先关闭增强开关；原生图表补丁如已安装仍保持原有行为。

- 正文与批量回复先核对格式、编号、公式占位符、引文编号、明显未译和模型自述；无效缓存不直接复用，每次请求最多三次尝试。失败的批量仍允许原引擎单段回退，保留原文不代表翻译成功。
- 根据源文件结构和原生布局分类保护图表内部文字、参考文献与页脚。可靠目录只翻译标题，保留章节号、页码和目标链接；某列翻译失败或放不下时保留原列并记录候选问题，不猜测正文的裁切边界。
- 每任务关闭富文本重排与表格内部翻译，以重现已认可的试验版行为，不修改用户原生保存值。自动术语抽取仍遵从主插件设置；本机当前保持开启。
- 原生生成后完成目录重建、参考文献/页脚矢量恢复和版面候选检查，再以原生文件名交给主插件回挂。旁边的 `*.quality-checks.json` 只记录计数、页码、坐标及摘要，不保存正文、提示或凭据。

当前适配 Server 4.1.7 的已知公共执行入口、pdf2zh-next 2.9.0 / BabelDOC 0.6.2 和 OpenAI 兼容服务。原版 1.x 与独立 exe 保持原生流程；使用其他 2.x 服务或不同引擎版本时关闭增强后使用原生流程。支持不分段的整篇 mono、LR、译文优先与交替页面；指定页码、仅保留译页及分段翻译会在模型请求前停止并提示关闭增强，复杂 OCR 尚未验收。没有全页重新流排或视觉模型自动修图，固定段落区域的大留白仍可能存在；检查报告不等于语义验收。

## 翻译历史清空修复

旧页面只删除浏览器缓存，刷新又将 Server 的历史合并回来。新版保存本机页面的清空时间，并在历史合并时过滤旧记录；清空之后完成的任务正常保留，包括清空时仍在翻译的任务。确认操作改为页面内对话框，避免内置查看器不显示原生 confirm 的情况。取消不会删除记录。

清空仅作用于当前服务地址的本机页面历史列表，不删除原文/译文、不停止任务，也不清空 Server 内存或其他浏览器的存储。更换服务地址会使用另一个页面存储。

插件打开服务页面前会对所配置 Server 目录中的 `index.html` 应用相同修复。只处理已知历史模块；不匹配的页面拒绝覆盖，已修复页面重复打开不会重写。更新页面不需要重启 Server，已有页面刷新后生效。

已安装旧子插件而希望只修复页面，可在仓库目录运行：

```powershell
node .\server-fix\install-history.cjs 'D:\softwares\zotero-pdf2zh\server'
```

## 安装与构建

从当前发布楼下载 `pdf2zh-companion-2.1.0.xpi`，通过 Zotero 插件管理器安装。首次配置继续使用主插件的回环服务地址，以及 `extensions.zotero.pdf2zh.companion.serverPython` / `serverScript`。不要在源码填写本机路径、密钥或用户偏好。

```powershell
node .\tests\smoke.js
node .\tests\environment.js
node .\tests\history.js
python .\tests\windows-native.py
.\build.ps1
.\tests\release.ps1
```

构建输出在 `dist/`：XPI 与包含版本、下载地址和 SHA-256 的 `updates.json`。CI 只测试和生成构建产物，不并发修改发布楼。仓库保持私有；GitHub 下载和更新清单需要有权限的认证，不能保证 Zotero 的匿名自动更新。手动安装 XPI 不依赖匿名更新。

唯一主源码在 `src/`。`tests/local-runtime.cjs` 为维护电脑的实际官方 Python 路径回归，不提交翻译、不调用模型；其他机器应使用通用测试或配置自己的环境。原生后台进度修复见 `server-fix/README.md`，更新历史页面无需重新安装该执行器补丁。

本版同时保留此前本机 2.0.1 的环境修复：读取所选 Python 的真实 `sys.prefix` / `sys.base_prefix`，支持官方 venv 与标准/自定义 Conda，并合并 Windows 的 Path/PATH。验证结果及尚未验证的真实界面范围见 `VERIFICATION.md`。
